# GYMRECORD

手機優先的本機健身紀錄 APP。以 Push、Pull、Leg、Upper、Lower 五種分日菜單開始，逐組記錄重量與次數。

## 開始使用

需要 Node.js。於此資料夾執行：

```powershell
npm install
npm run dev
```

在同一台電腦開啟終端顯示的 `http://127.0.0.1:5173/`。正式版本可用 `npm run build` 建立於 `dist/`。

## 目前功能

- 可編輯、新增、刪除訓練菜單與動作。
- 從菜單開始訓練，帶入上次完成的重量與次數。
- 逐組修改重量、次數，標記暖身組、完成組、增加或刪除組別。
- 訓練中自動儲存；重新開啟後可繼續未完成訓練。
- 在日曆查看有訓練的日期，並檢視當天的重量與組數、各動作最高重量趨勢。
- 可切換公斤／磅、使用組間計時器。
- 匯出／匯入 JSON 完整備份，以及匯出 CSV 訓練紀錄。

所有訓練內容儲存在目前瀏覽器的 IndexedDB，沒有帳號與遠端資料庫。清除瀏覽器網站資料或換裝置前，請從設定匯出備份。PWA 的離線快取會在正式建置後啟用；安裝到手機主畫面需要透過支援的安全來源提供 APP。

## 資料結構

菜單含動作與預設值。開始訓練時建立當次快照，保存每一組的實際重量、次數與完成狀態，因此修改菜單不會更動過去紀錄。重量在資料庫中以公斤儲存，顯示時依設定換算。
